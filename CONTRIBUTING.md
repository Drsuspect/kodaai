# Collaboration and Contributions

This repository is a public project showcase. KODAAI’s proprietary core source code is maintained privately and is not accepting unrestricted code contributions.

## We welcome

- accessibility research collaboration;
- feedback from blind and visually impaired users;
- partnerships with education and assessment organizations;
- responsible industrial voice-interface use cases;
- Turkish NLP, LLM, TTS, and speech research collaboration;
- evaluation methodology and standards discussions;
- institutional, technology, and investment partnerships.

## Proposals

A useful proposal should explain:

1. the real user or organizational problem;
2. the intended users and context;
3. the accessibility or operational benefit;
4. privacy, security, and safety considerations;
5. what each party could contribute;
6. how success could be measured.

Do not submit confidential information, personal data, credentials, production logs, private datasets, or proprietary documents through a public issue.
